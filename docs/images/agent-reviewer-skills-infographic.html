Key experiments

1

Prompt ablations

Tested zero-shot, generic, full skill, principles only, IDs only, trimmed and hybrid prompts on security code

Found apparent gains for compact guidance, but large run-to-run variance and weak references

2

Rhodes evaluations

Tested the code-quality skill on synthetic examples and real doit code, several runs, a second model

Found synthetic results distorted by answer leakage; real reviews changed emphasis only

synthetic withdrawn
3

Local-model pilot

Tested Qwen3 Coder and Devstral through Pi and Ollama on a pinned real repository

Found no validated improvement; some guided runs produced no usable final review

4

Final real-code A/B

Tested regular Codex review against a lean skill of mnemonic IDs, three runs each

Found no material advantage: slightly higher recall, fewer distinct validated defects

strongest closing test
